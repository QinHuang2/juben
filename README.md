# juben｜剧本与分镜输出 Skill

仅在用户主动调用时使用。普通“写剧本”“写分镜”请求不会自动套用此技能。

## 调用

```text
$juben
请根据下面的剧情、人物和资产表输出第1集分镜。
……
```

也可明确说“这次使用 juben skill”。每次独立任务需重新主动调用；同次任务的补充资料和修改继续沿用，完成后不默认延续。

## 输出

- 文学稿：集数、场次、道具、人物、△画面与自然对白。
- 分镜稿：一镜一段，使用处直接`@准确资产名称`，同段包含时长、景别、运镜、场景／动作／表情、光影和声音。
- 按需提供平台片段格式和资产／衔接附件，不强制整套生产文件。

不预设画风、不要求慢动作、不固定镜长；保留源稿剧情、台词和已锁资产，不自动生成图片或付费视频。

## 提供资料

剧情或源稿、人物设定、集数与时长要求、资产准确名称及状态、已有声音与平台格式。已提供的信息不重复询问；关键缺项会澄清，获准先出草稿时标记待确认。

## 安装与显式调用

将仓库内容放入本机技能目录下的`juben/`，保留`SKILL.md`、`agents/openai.yaml`和`references/`。Codex配置已设置`allow_implicit_invocation: false`。其他客户端须支持对应的显式调用策略；仅复制指令文本不能保证客户端不会自动选用。

## 来源

格式组织借鉴[smy-seedance-storyboard](https://github.com/liangdabiao/smy-seedance-storyboard)的连续剧本与时间轴输出思路；本技能独立编写，不复制其风格与制作标准，不包含个人项目原稿、声音、资产图或经验库。
